阶段一：手机配网与 C 语言 GPIO 硬件驱动时序全景

详细记录系统从上电启动、自动连网、手机 AP 弹窗配网、到硬件长按 3 秒重置的全节点代码调用链路

树莓派通电开机，systemd 拉起 C 语言硬件控制器
systemd 纯 C 守护进程
Debian 内核挂载文件系统后，首先启动 `debugbox-gpio.service`。C 二进制守护进程打开内核 GPIO 字符设备，接管引脚，并创建本地通信套接字。白灯默认置为中速快闪（CONNECTING）。
执行的文件与代码位置：
config/systemd/debugbox-gpio.service → 配置在 local-fs.target 之后启动守护进程
src/c_gpio/main.c (main: L115) → 打开 /dev/gpiochip0，创建 /run/debugbox_gpio.sock (权限 0666)
src/c_gpio/gpio_controller.c (init & start) → 申请 GPIO 17 (上拉输入) 和 GPIO 27 (输出)，拉起 led_worker 与 btn_worker 线程

systemd 启动网络总控服务，检测 Wi-Fi 连通状态
systemd Python 胶水层
启动 `debugbox-network.service`，总控进程读取配置参数，并通过 Linux 原生 NetworkManager 轮询无线网卡连接状态。
执行的文件与代码位置：
config/config.yaml → 读取引脚编号 17/27，热点前缀 DebugBox，检测超时参数
src/network_service.py (start: L106) → 执行 start() 主生命周期，等待 NetworkManager 连网握手
src/wifi_portal/wifi_controller.py (is_connected_to_wifi) → 执行 nmcli -t -f DEVICE,TYPE,STATE device 检查 wlan0 状态
↓
3
成功连接已知网络，跨进程通知 C 守护进程切换心跳灯
Socket 客户端 Socket 服务端 硬件就绪
发现已经连上已知路由器（如当前的小米路由器，拿到 IP: 192.168.31.107），Python 客户端连接 `/run/debugbox_gpio.sock` 发送 `SET ONLINE` 指令。C 语言线程瞬间将白灯切换为心跳双闪。
执行的文件与代码位置：
src/gpio_manager/c_gpio_client.py (set_state) → 打开 /run/debugbox_gpio.sock，向 C 进程下发 "SET ONLINE\n"
src/c_gpio/main.c (accept 循环: L165) → C 守护进程解析指令，调用 gpio_controller_set_led_state(&ctrl, LED_STATE_ONLINE)
src/c_gpio/gpio_controller.c (led_worker: L63) → 独立 pthread 按照 0.1s开/0.15s关/0.1s开/1.65s关 精准循环，系统进入就绪态

在新工厂未搜到已存网络，总控自动启动 AP 配网模式
网络总控 NetworkManager
开机超时未连网，或长按按键触发重置后，`network_service.py` 执行 `_enter_ap_mode()`，通过 NetworkManager 开启名为 `DebugBox-8B53` 的热点（静态 IP: 192.168.4.1）。
执行的文件与代码位置：
src/network_service.py (_enter_ap_mode: L133) → 通知 C 守护进程切换为 AP_MODE (慢闪)，调用 wifi.start_hotspot_ap()
src/wifi_portal/wifi_controller.py (start_hotspot_ap: L165) → 执行 nmcli con add mode ap ipv4.method shared 生成热点连接并激活

2
NetworkManager 自动加载 DNS 泛解析，Python 开启 Web 80 服务
dnsmasq 泛解析 Captive HTTP
NetworkManager 内部的 dnsmasq 自动读取泛解析规则，将一切外网域名解析为 `192.168.4.1`。同时 Python 开启端口 80 监听，准备拦截苹果/安卓探针。
执行的文件与代码位置：
/etc/NetworkManager/dnsmasq-shared.d/00-captive-portal.conf → address=/#/192.168.4.1 (将所有 DNS 请求劫持为本机 IP)
src/wifi_portal/server.py (PortalServer.start: L145) → 监听 0.0.0.0:80，预载入 HTML 模板，严禁任何 HTTP 缓存

3
工人手机连入热点，触发全自动全屏弹窗
自动弹窗 探针拦截
手机连入热点，后台向 `captive.apple.com` 发出探测，被拦截并返回 302 重定向至 `http://192.168.4.1/`，手机操作系统全屏弹出配网页。页面异步请求周边 Wi-Fi 列表。
执行的文件与代码位置：
src/wifi_portal/server.py (do_GET: L31) → 拦截 Host 与 /hotspot-detect.html、/generate_204，返回 302 跳转
src/wifi_portal/templates/index.html → 渲染自适应触屏 UI，调用 fetch('/api/scan') 刷新车间 Wi-Fi
src/wifi_portal/wifi_controller.py (scan_wifi_list) → 执行 nmcli dev wifi list --rescan，去重排序后返回 JSON 给前端
↓
4
工人点选密码提交，热点平滑关闭，树莓派接入新网络
前端成功卡片 网络切换 心跳双闪恢复
工人点击“保存并连接”，前端立即展示绿色指引卡片；树莓派收到密码后关闭自身 AP 模式，切入 Station 模式连接车间网络。联网成功后，C 守护进程将白灯切为心跳双闪。
执行的文件与代码位置：
src/wifi_portal/templates/index.html (submitConnect: L430) → 发送 POST /api/connect，页面替换为“配置已发送，观察白灯心跳双闪”指引
src/wifi_portal/server.py (do_POST: L73) → 响应 ok 后，延迟 0.8s 异步调用 on_worker_submitted_wifi
src/wifi_portal/wifi_controller.py (connect_wifi: L215) → 执行 nmcli dev wifi connect password 完成联网
src/gpio_manager/c_gpio_client.py → src/c_gpio/main.c → 发送 SET ONLINE，白灯恢复心跳双闪，工人和工程师可远程连入！
1
工人物理长按复位按键（GPIO 17 / Pin 11）
物理触点 10ms 采样消抖
按键一端接 GPIO 17，另一端接 GND。按下瞬间电平由 HIGH 变 LOW，C 守护进程的 `btn_worker` 线程以 10ms 频率采样消抖并记录按下起始时间戳。
执行的文件与代码位置：
src/c_gpio/gpio_controller.c (btn_worker: L95) → gpiod_line_request_get_value(ctrl->btn_request, 17) 检测电平闭合
↓
2
长按满 3.0 秒触发判决，LED 硬件级狂闪提示松手
单调时钟 急促狂闪
通过 `clock_gettime(CLOCK_MONOTONIC)` 计算按下时长。达到 3.0 秒瞬间，C 守护进程立即把白灯切为 `RESETTING`（0.08s 开/0.08s 关急促狂闪），工人看到狂闪便知重置已生效，随即松手。
执行的文件与代码位置：
src/c_gpio/gpio_controller.c (L110) → now - press_start >= 3.0s 判定达成，设置 current_state = LED_STATE_RESETTING
src/c_gpio/main.c (on_reset_triggered: L25) → C 守护进程捕获回调，执行系统异步命令：bash /opt/debugbox/scripts/on_network_reset.sh &
↓
3
执行重置脚本，清空已存 Wi-Fi 配置并重启配网
Shell 脚本 NetworkManager
脚本枚举所有 `802-11-wireless` 连接（安全过滤空格），执行 `nmcli connection delete` 删除车间老网络，并重启 `debugbox-network.service`，无缝流转进入流程 2 的 AP 模式（白灯慢闪）。
执行的文件与代码位置：
scripts/on_network_reset.sh (L9) → while IFS=: read -r conn type; do nmcli connection delete "$conn"; done
scripts/on_network_reset.sh (L16) → systemctl restart debugbox-network.service

文件路径 技术栈 / 语言 角色与职责 运行环境 / 权限
src/c_gpio/gpio_controller.h C 语言头文件 定义 LED 状态枚举、引脚配置结构体、多线程与 libgpiod v2 函数原型 编译期头文件
src/c_gpio/gpio_controller.c C 语言 / libgpiod v2 内核字符设备驱动交互、微秒级可中断 LED 闪烁波形线程、10ms 按键长按消抖线程 树莓派本地编译 (GCC 14.2)
src/c_gpio/main.c C 语言 编译生成 debugbox_gpio_daemon 守护进程与 gpio_ctl 命令行工具，监听 /run/debugbox_gpio.sock root 常驻 (内存仅 1.5MB)
src/gpio_manager/c_gpio_client.py Python 3 (socket) 封装 UNIX Domain Socket 客户端，供 Python 服务毫秒级向 C 守护进程发送 SET ONLINE 等指令 用户态 Python 模块
config/00-captive-portal.conf dnsmasq 规则 address=/#/192.168.4.1：让 NetworkManager 自带的 dnsmasq 将所有 DNS 查询解析为本机，促使手机强行弹窗 /etc/NetworkManager/dnsmasq-shared.d/
src/wifi_portal/server.py Python 3 (http.server) 零依赖轻量 HTTP 80 服务，拦截苹果/安卓 Captive 探针重定向至根路径，提供扫描与连接 API root 监听 80 端口
src/wifi_portal/templates/index.html HTML5 / CSS3 / Vanilla JS 工人手机配网自适应网页，支持 Wi-Fi 信号格显示、密码显隐开关、提交后立刻展示白灯心跳指引卡片 手机浏览器运行
src/wifi_portal/wifi_controller.py Python 3 (subprocess) 封装 Linux nmcli 命令：热点创建 (AP)、周边扫描、删除老配置、连入新网络 系统管理进程
src/network_service.py Python 3 (大脑总控) 阶段一业务大脑：开机连网侦测、超时自动切 AP 模式、监控网络健康、掉线自愈 systemd 守护进程
scripts/on_network_reset.sh Bash Shell 脚本 长按满 3 秒时由 C 程序调用的清网脚本：安全删除带空格的旧 SSID，重启网络总控进入配网 root 权限可执行
config/systemd/*.service systemd 单元 配置 debugbox-gpio.service 与 debugbox-network.service 开机自启与失败自重启规则 /etc/systemd/system/
