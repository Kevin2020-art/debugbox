核心决策 1
为什么推荐单线程 poll()？
多线程（线程A读串口、线程B管Socket）在 C 语言中容易产生竞态条件，需要引入互斥锁（Mutex）与环形缓冲队列。而 Linux 核心的 poll() 能将串口和 Socket 统一看作事件源，单线程事件驱动，彻底避免死锁，代码逻辑像线性脚本一样直观。
poll(&poll_fds, nfds, timeout_ms);
核心决策 2
<termios.h> RAW 原始模式
Linux 默认对串口启用“终端处理模式”（会自动吃掉回车符、转换换行、拦截 Ctrl+C）。我们在 C 中将其设置为纯 RAW 模式（关闭 ECHO、ICANON、ISIG 等），确保单板发出来的十六进制数据、回车和转义序列 100% 原汁原味。
cfmakeraw(&tio); cfsetspeed(&tio, B115200);
核心决策 3
毫秒时间戳与防爆卡保护
使用高精度的 clock_gettime(CLOCK_REALTIME) 获取毫秒。为保护 SD 卡寿命，采用内存按行批次刷盘机制。当文件达到 20MB 阈值时自动轮转切割并压缩，磁盘最多保留 50 个最新切片（约 1GB），超限自动清除最老日志。
snprintf(buf, len, "[%04d-%02d-%02d %02d:%02d:%02d.%03ld] ...")
核心决策 4
UNIX Socket (AF_UNIX) 优势
比起网络端口（如 127.0.0.1:8888），本地套接字 /run/debugbox_serial.sock 纯走内核内存零网络栈开销，延迟低于 10 微秒；且依赖 Linux 标准文件权限（0666）保护，外网绝对无法越权扫描该端口，具备天生工业级安全。
socket(AF_UNIX, SOCK_STREAM, 0);
